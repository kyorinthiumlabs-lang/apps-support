# KyorinthiumLabs Support Site

This folder is a ready-to-publish GitHub Pages support site for multiple mobile apps.

## Suggested GitHub setup

1. Create a public GitHub repository:
   `apps-support`
2. Upload all files inside this `support-site` folder to the repository root.
3. Go to GitHub repository settings:
   `Settings` -> `Pages`
4. Set:
   `Source: Deploy from a branch`
   `Branch: main`
   `Folder: / (root)`
5. Your URLs should become:
   `https://tolgakurt.github.io/apps-support/`
   `https://tolgakurt.github.io/apps-support/privacy.html`

## Store listing URLs

Use these in App Store Connect / Google Play Console:

- Support URL: `https://tolgakurt.github.io/apps-support/`
- Privacy Policy URL: `https://tolgakurt.github.io/apps-support/privacy.html`

If your GitHub username or repository name is different, replace the URLs accordingly.
